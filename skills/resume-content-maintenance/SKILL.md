# Resume and content maintenance

1. Ask for the source resume, requested edits, intended audience, and whether the user wants factual updates, recommendations, or both.
2. Treat current profile content as existing claims, not proof. Require confirmation for new employers, dates, metrics, credentials, skills, or materially stronger wording.
3. Make factual edits only in the canonical profile package. Do not duplicate profile facts in page components, prompts, or MCP handlers.
4. Label recommendations clearly and do not apply unsupported claims without confirmation.
5. Check the reference site, generated PDF, assistant grounding, and MCP resources/tools for consistency.
6. Run profile tests, leakage checks, typecheck, and relevant site/MCP tests.
7. Report confirmed factual changes, recommendations not applied, and any unresolved evidence gaps.
